# Documentation

[Hermes × Devin](../README.md) is a community add-on for delegating coding tasks
through the Devin CLI. Start with installation, then choose the guide for your target.

## Getting started

- [Installation](getting-started/installation.md) covers prerequisites, sign-in,
  plugin setup and first-run settings.
- [Usage](getting-started/usage.md) covers Desktop, chat examples, commands and tools.

## Guides

- [Local model controls](guides/model-controls.md) explains model search, Fusion,
  thinking controls and saved defaults.
- [Cloud sessions](guides/cloud-sessions.md) explains account choices, remote
  permissions, cancellation confirmation and reconnect checks.
- [Devin MCP server](guides/devin-mcp.md) adds optional hosted tools alongside the plugin.

## Reference

- [Configuration](reference/configuration.md) lists every setting, default and limit.
- [Approval and permissions](reference/approval-and-permissions.md) explains the
  launch gate and Local permission modes.
- [Known limitations](reference/limitations.md) records unsupported behavior and validation scope.

## Development

- [How it works](development/how-it-works.md) follows a run through ACP or print mode.
- [Process trees](development/process-tree.md) explains cleanup on Windows and POSIX.
- [Run data and events](development/run-data-and-events.md) describes snapshots and live events.
- [Testing](development/testing.md) covers the fake CLI, contract checks, Desktop smoke and lint.
